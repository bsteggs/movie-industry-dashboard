# Movie Industry Dashboard (Power BI)

This Power BI dashboard explores trends in the U.S. movie industry from 1995 to 2021. It visualizes data on ticket sales, box office revenue, theatrical releases, and performance by genre and distributor.

## Overview

**Dataset Source**:  
[Kaggle - Movie Industry Data](https://www.kaggle.com/) (public dataset)

**Tool Used**:  
Microsoft Power BI Desktop

**Timeframe**:  
1995–2021

## Key Features

- Total Tickets Sold  
- Total Box Office Revenue  
- Average Ticket Price (calculated)  
- Top Grossing Movie  
- Year-over-Year Revenue Trend  
- Wide Releases by Year  
- Top 5 Genres by Revenue  
- Top 5 Distributors by Revenue  
- Movie Table with % of Total Revenue  

## Slicers for Dynamic Filtering

- Genre  
- Year  
- Distributor  

## Design Notes

- Responsive layout designed for interactivity
- Clean dark theme for readability and contrast
- Custom tooltips added for enhanced user experience
- Icons and design elements used for visual clarity

## How to Use

1. Open the `.pbix` file in Power BI Desktop  
2. Use the slicers to explore data by year, genre, or distributor  
3. Hover over charts to view detailed tooltips  
4. Customize or extend the dashboard as needed

## Files Included

- `MovieDashboard.pbix` – Power BI report file  
- `assets/` – Icons and design elements
